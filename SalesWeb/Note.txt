Using Ckeditor,CKfinder,
Step 1: download 2 folder
Step 2: add ckeditor and ckfinder script in 2 folder
Step 3: Add references move to ckfinder - Bin - Debug - Select CKFinder.dll
Step 4: replace js below 
Important: Using TextAreaFor function to insert CKEditor
 <script>
        $(document).ready(function () {
            CKEDITOR.replace('txtDetail', {
                customConfig: '/Content/CK/ckeditor/config.js',
                extraAllowedControl: 'span',
            });
        })
</script>
with txtDetail is a Id of div tag

Using browse input file by CKfinder

<div class="custom-file">
                            @Html.TextBoxFor(x => x.Image, new { @class = "form-control", @id = "txtImage" })
</div>
<div class="input-group-append">
                            <input type="button" value="Browse" onclick="BroserServer('txtImage')" />
</div>

function BroserServer(field) {
            var finder = new CKFinder();
            finder.selectActionFunction = function(fileUrl){
                document.getElementById(field).value = fileUrl;
            };
            finder.popup();
}
